# Native Dialog & Unmount Transitions

A pure HTML & CSS demo showcasing modern native dialog and popover animations using:

- `@starting-style`
- `transition-behavior: allow-discrete`
- Native `<dialog>`
- Native Popover API

## Features

- Bounce dialog entrance
- Smooth dialog exit
- Slide-up popover animation
- Pure CSS
- Responsive layout
- No JavaScript animation logic

## Files

```
native-dialog-unmount-transitions/
├── demo.html
├── style.css
└── README.md
```

## Purpose

Demonstrates modern CSS transition techniques for native dialog and popover components using the latest browser features without relying on animation timeouts or JavaScript.
