# Synthwave Grid Line

A smooth pure CSS text animation inspired by retro synthwave aesthetics, featuring glowing typography, a perspective grid, and a luminous striped sun.

## Features

- Pure HTML and Vanilla CSS
- No JavaScript or external dependencies
- Animated perspective grid
- Neon synthwave text glow
- Retro striped sun effect
- Responsive typography
- Dark-mode friendly
- Hardware-accelerated animation properties
- `prefers-reduced-motion` accessibility support

## How It Works

The effect combines:

- CSS gradients for the synthwave background
- Repeating linear gradients for the retro grid
- CSS perspective transforms to create depth
- Layered text shadows for the neon typography
- Animated transforms and opacity for smooth motion
- CSS keyframes for the grid, sun, text, and underline effects
